# 🎮 Scratch Ping Pong – Classic Pong Game in the Browser

A modern, browser-playable remake of the classic Pong game, built entirely using **MIT Scratch**, exported through **TurboWarp**, and deployed on **GitHub Pages**.

## 🧩 Features

| Feature | Description |
|--------|------------|
| 🕹 Two Player Mode | Player 1 (W/S), Player 2 (Up/Down Arrow) |
| 🎯 Angle-Based Ball Bounce | Ball direction changes depending on hit location |
| ⚡ Adaptive Speed Boost | Ball speed increases after every paddle hit |
| 🏆 Win Condition Logic | Displays winner based on score |
| 🔄 Restart System | Restart game with button or space key |
| 🌐 Web Export | Packaged via TurboWarp to run like a real web game |

## 🛠 Tech Stack

| Tool | Purpose |
|------|--------|

## 🧠 Gameplay Controls

| Player | Move Up | Move Down |
|--------|--------|----------|
| Player 1 | W | S |
| Player 2 | ↑ Up Arrow | ↓ Down Arrow |
